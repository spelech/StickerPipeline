# 🏷️ Sample Sticker Pipeline Demonstration

This directory contains live sample artifacts generated by the **StickerPipeline** processing engine.

---

## 🎨 Pipeline Stages

### Stage 1: AI Generated Raw Image (`sample_raw.jpg`)
The original raw image generated by OpenWebUI / LibreChat / LiteLLM.

### Stage 2: Background Removed (`sample_nobg.png`)
`rembg` (u2net / ONNX CPU) extracts the foreground puppy subject into a transparent RGBA PNG.

### Stage 3: Die-Cut White Offset Border (`sample_bordered.png`)
OpenCV kernel dilation applies a smooth 25px white contour border around the subject, ready for Cricut Joy 2 cutting.

### Stage 4: 300 DPI Grid Sticker Sheet (`sample_sheet.png` & `sample_sheet.pdf`)
ReportLab & Pillow assemble processed stickers into printable high-DPI page sheets formatted for Epson EcoTank network printing and Cricut Joy 2 mat alignment.
